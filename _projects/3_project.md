Park Fountain Explorer is a location-centered project designed around discovery. The interesting part of this work is not just the data itself, but how the interface helps people move through space, filter options, and understand results quickly.

## What I focused on

- Designing around map and location context instead of a plain content list.
- Presenting data in a way that supports scanning and comparison.
- Creating a lightweight browsing experience for a visually oriented workflow.

## Why it matters

Projects like this are useful practice for product thinking because they force the interface to carry a lot of responsibility. Good layout, clear state changes, and sensible information hierarchy make the difference between a usable tool and a frustrating one.
