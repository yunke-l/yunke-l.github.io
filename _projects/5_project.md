This project moves away from product UI and into analytical tooling. The challenge is converting raw visual input into information that can be measured, compared, and reasoned about.

## What I focused on

- Working with image-based data in a systematic way.
- Turning messy visual input into a repeatable processing pipeline.
- Keeping outputs useful for interpretation rather than producing opaque results.

## Why it matters

Analytical projects sharpen a different set of instincts: precision, repeatability, and careful handling of input data. That perspective still helps in web engineering because it encourages disciplined thinking and clearer problem decomposition.
