This repository supports the server-side layer of the movie reviewer platform. It is centered on API design, data handling, and the practical concerns that appear when a frontend starts relying on consistent backend behavior.

## What I focused on

- Structuring endpoints clearly enough for the frontend to consume with minimal friction.
- Managing review-related data flows and persistence.
- Keeping the backend simple, understandable, and aligned with product needs.

## Why it matters

Working on the API side gave me a better sense of how frontend decisions and backend contracts shape each other. It also reinforced the importance of building interfaces with data models and service boundaries in mind.
