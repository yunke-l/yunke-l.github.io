Location-centered project built around discovery, filtering, and fast spatial browsing.

## Focus

- Designing around map and location context instead of a plain list.
- Presenting data for fast scanning and comparison.
- Keeping the browsing flow lightweight and visual.

## Takeaway

This project sharpened how I think about information hierarchy, state changes, and interface decisions in discovery-heavy products.
